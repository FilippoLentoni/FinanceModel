# Forward hourly modeling and actual inference evidence

## Why
The approved beta comparison requires one isolated synthetic book for every
implemented/evaluated approach, exact model-input content, actual financial
research/Codex review, and durable hourly accounting. Current daily serving and
historical evaluators do not themselves implement that forward workflow.

## What Changes
- Add an EC2 runtime registering controls, evaluated optimizer variants, frozen
  RL exports, direct Codex, actual LangGraph, Jev and Qwen with explicit blockers.
- Capture exact solver arrays, named actor observations, source/prepared news and
  public Codex prompts/responses at actual inference boundaries.
- Add bounded dated S&P constituent/public RSS retrieval workers, review and
  separate nontrading half-hour evidence.
- Use existing FinancialPlanning evidence/portfolio/decision/history stores with
  permanent slot IDs, recoverable leases and bounded query paths.
- Add a genuine forward point-quote evaluator sharing unchanged daily fill/cost
  mechanics; prohibit hindsight execution from late-acquired daily opens.
- Freeze genuine forecasts and reconcile through durable pending/observation-time
  indexes without rewriting predictions. Migrate compatible contracts to1.12.0.
- Preserve compute/vendor approval, budgets, gamma/prod isolation and existing
  user-portfolio confirmation. Runtime executes only new isolated paper books.
