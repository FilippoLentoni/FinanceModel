# Proposal

## Why
News sensitivity is not an out-of-sample performance experiment, and existing saved paper capital is not the requested separate $100 study. We need runnable matched forward research and explicit profile isolation.

## What Changes
- Add a runnable matched price-only versus news-enriched optimizer paper experiment with frozen prices, common initial holdings, constraints and transaction costs.
- Require vintage and publication/availability evidence before historical performance claims; return explicit coverage blockers when absent.
- Add separate caller-bound $100 VOO/GOOGL paper profile initialization through existing lifecycle APIs, preserving existing portfolios.
- Keep PPO/LLM policy eligibility honest and use existing news feature adapters.
