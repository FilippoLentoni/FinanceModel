# Add approval-gated current-book offline Qwen bridge

## Why
The implemented Qwen fixed-role swarm uses a historical simulator book. Its historical output cannot become the hourly experiment's current-book policy, and a prepared first-role message is not inference.

## What Changes
Add a typed beta backend proposal, approved one-decision network-isolated GPU worker branch, immutable original role captures and strictly bound read-only hourly reuse. Preserve native message construction, model revision, simplex policy, budget/runtime/token caps and independent CPU staging/GPU approval. Use existing private Model context/cost outbox records and offline channels, without a new public contract, table, network grant or portfolio ledger.

## Impact
FinanceModel only. No weights download, compute launch, human approval or AWS deployment is performed by implementing/tests. Missing pinned weights and approvals remain external live-coverage blockers. Hard container loss without an exported role response is indeterminate/unusable and permanently prevents automatic relaunch; original inputs are never regenerated to fill a gap.
